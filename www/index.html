NAME

timui.h (pronounced "timmy") - tiny immediate-mode UI for terminals

SYNOPSIS

#define TIMUI_IMPLEMENTATION
#include "timui.h"

TimuiConfig cfg = {0};
Timui *ui = 0;
timui_open(&cfg, &ui);

DESCRIPTION

timui.h is a single-header C99 immediate-mode TUI library for modern terminals. It brings DOS-era ergonomics to Kitty-class terminal protocol reality. No ncurses. No runtime circus.

The library is designed for a very specific contradiction:

  • It is old-school C, header-only, plain values, file descriptors, and make.
  • It targets modern terminals: truecolor, synchronized output, Kitty keyboard, SGR mouse, bracketed paste, OSC 8 hyperlinks, and Kitty graphics.
  • It is serious engineering wrapped in a knowing joke: using a header-only C library for TUIs while Go, Rust, TypeScript, and Python eat CLI tooling is absurd in exactly the right way.

CAPABILITIES

The API is built for single-binary systems tools, file managers, debuggers, dashboards, and local agent tools.

  • Widgets: Labels, panels, function bars, buttons, checkboxes, radios, input lines, text areas, listboxes, tables, trees, command palettes, and menus.
  • Rendering: A cell buffer and truecolor diff renderer ensures unchanged frames emit nothing.
  • Input Parser: Incremental parser handles legacy CSI, Kitty keyboard, SGR mouse (with wheel & click position), focus events, text, and UTF-8.
  • Async Work: timui_post allows worker threads to post messages safely while the UI thread owns the terminal.

Figure 1: Executing `make run-chat`

Or start smaller. The smallest useful program opens the terminal, draws one frame at a time, and lets Escape leave without making a mess of your shell. 

#include <unistd.h>

#define TIMUI_IMPLEMENTATION
#include "timui.h"

int main(void) {
    TimuiConfig cfg = {0};
    Timui *ui = 0;

    cfg.title = "hello timui";
    /* POSIX file descriptors, not stdio FILE* streams. */
    cfg.input_fd = STDIN_FILENO;
    cfg.output_fd = STDOUT_FILENO;
    cfg.profile = TIMUI_PROFILE_AUTO;
    cfg.flags = TIMUI_FLAG_ALT_SCREEN | TIMUI_FLAG_RESTORE_ON_EXIT;
    cfg.theme = TIMUI_THEME_DOS_BLUE;

    if (timui_open(&cfg, &ui) != TIMUI_OK) return 1;

    while (!timui_should_quit(ui)) {
        /* Stack locals, not heap allocations: f is this frame,
           and root is recomputed after begin handles input/resize. */
        TimuiFrame *f = 0;
        TimuiRect root;

        /* Begin polls input and prepares this frame; leave if no frame is available. */
        if (!timui_begin(ui, &f)) break;
        root = timui_root(f);
        timui_label(f, root.x + 2, root.y + 2,
                    TIMUI_STR_LIT("hello from one header"),
                    /* 0x59ee3f is timui green: RGB 89, 238, 63. */
                    timui_style_make(0x59ee3f, TIMUI_COLOR_DEFAULT, 0));
        if (timui_key_pressed(f, TIMUI_KEY_ESCAPE)) timui_quit(ui);
        timui_end(f);
    }

    timui_close(ui);
    return 0;
}

TESTING

The library is not a toy. It maintains 196 verified tests via make test. Continuous integration runs address, undefined, and thread sanitizers. Golden staleness checks and Tier A libvterm round-trip verification are enforced.

BUGS AND LIMITATIONS

The current implementation has known constraints:

  • Windows Support: Win32 ConPTY is explicitly a stub returning unsupported. The POSIX raw-mode terminal backend is currently required.
  • Text Shaping: Contains CJK/emoji wide glyph rendering and useful Hebrew/Arabic approximation, but full UAX #9 bidi, complex grapheme clusters, and ZWJ emoji remain unimplemented.
  • API Stability: Currently version 0.2.0. The API is highly functional but not 1.0 stable.

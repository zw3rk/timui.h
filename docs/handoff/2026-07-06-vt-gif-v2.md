- **Phase 1** — text face is `stb_truetype` over a bundled subset of DejaVu Sans
  Mono (`tools/vendor/vt_font_ttf.h`, `make gen-font-ttf`) + a glyph cache; any

  the flag-free default) *and* `--system-emoji` (Apple Color Emoji `sbix`, preferred

  two-pass: backgrounds then glyphs, so a 2-cell CJK/emoji glyph isn't overpainted)

  (msf_gif), `--frames-dir DIR` (PNG sequence → `ffmpeg` MP4/WebP; vt_gif stays
  ffmpeg-free).
- Docs: `docs/research/{kitty-gif-renderer,vt-gif-v2-plan}.md`, `USAGE.md`,

**Now also done (this session):** bundled **Unifont CJK** and the **golden-PNG
test** — so all four phases plus the bundled *and* system paths for CJK/emoji are
complete. The bundled-CJK blocker (fonttools can't subset Unifont's OTF —
`ValueError: expected 0 <= int <= 122`) was routed around via a **`.bdf` bitmap
face**: `tools/gen_cjk.py` parses `unifont.bdf`, packs the CJK/Hangul/Kana ranges
(39 764 glyphs) as 16×16 bitmaps, deflate-compresses to 635 KB, and `vt_gif`
inflates once at startup (`stbi_zlib`) and renders them scaled to the cell —
inserted after the outline/system faces (so `--system-fonts` still wins).

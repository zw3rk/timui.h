Idiomatic C99; work ONLY via `nix develop -c make <target>`. NO new vendored deps; NO crypto.

examples/irc.c — an RFC 1459/2812 client:
 - PARSER (pure, TDD-FIRST; split into examples/irc_proto.h): parse `:prefix CMD params :trailing` into a struct; handle PING/PONG, JOIN/PART, PRIVMSG/NOTICE, NAMES, QUIT, TOPIC, and numerics (RPL_WELCOME 001, RPL_NAMREPLY 353, RPL_ENDOFNAMES 366, RPL_TOPIC 332, ERR_*). Test HARD: positive vectors + malformed / truncated / missing-prefix / trailing-colon-in-params / multiple-spaces / CR-LF and no-CR edge cases.
 - NET: connect over PLAINTEXT TCP (6667; NO crypto — TLS is a noted follow-up needing a vetted lib) on a worker thread; the reader splits + parses lines and hands them to the UI ONLY via timui_post (docs/THREADING.md — only timui_post is cross-thread-safe; join the worker before timui_close, W14). Auto PING→PONG. Bounded reconnect/backoff.
 - UI (from the library widgets): channel/query buffers = timui_tabs; per-buffer scrollback (reuse the chat transcript-ring pattern, timestamps + the markdown/URL rich text); nick list = timui_table (or listbox); composer = timui_textarea handling `/join /part /msg /nick /me /quit` + plain lines → PRIVMSG to the active buffer; a 3-pane timui_split layout (tabs top · scrollback + nick-list middle · composer bottom) inside timui_border panels; a status line (nick · server · active channel · lag).
 - HEADLESS SMOKE: feed a CANNED server transcript (WELCOME → JOIN #chan → 353 NAMES → a few PRIVMSGs) through the message handler and render one frame (deterministic, no network); assert the channel tab, the messages, and the nick list all render. Optional best-effort live connect to a public server behind a flag.
 - MAKEFILE: build/irc + run-irc + check-irc (parser unit tests) + smoke-irc, each appended to its GROUPED section (general · run/rec/drive · check/smoke · packaging) — do not dump them at the end.

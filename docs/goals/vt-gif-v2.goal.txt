ARCHITECTURE: font = an ordered fallback chain of "faces". A Face maps a codepoint to a glyph: OUTLINE (stb_truetype grayscale coverage, blended fg-over-bg) or COLOUR (RGBA, composited like an inline image). rasterize(cp): first face with the glyph wins, else a tofu box. Default chain (all BUNDLED -> reproducible/CI): DejaVu Sans Mono -> Unifont (CJK/BMP) -> Twemoji. Flags read OS font FILES directly (no framework dep), falling back to bundled + a stderr note: --system-fonts -> macOS PingFang.ttc (CJK, stb_truetype); --system-emoji -> Apple Color Emoji.ttc (sbix PNG strikes). Cell size runtime (cellw,cellh; default 8x16) via --scale/--cell-h.

## Architecture: font = an ordered fallback chain of "faces"
A Face resolves a codepoint to a glyph: an OUTLINE face (stb_truetype → grayscale
coverage, blended fg-over-bg) or a COLOUR-BITMAP face (RGBA, composited like an
inline image). `rasterize(cp)`: try faces in order, first with the glyph wins, else
draw a tofu box. Default chain (all BUNDLED → reproducible/CI): DejaVu Sans Mono →
Unifont (CJK/BMP) → Twemoji (colour emoji). Flags swap the OS fonts in by reading
the font FILES directly (no CoreText/framework dependency), falling back to the
bundled face + a stderr note on failure:
  --system-fonts  → CJK face = macOS /System/Library/Fonts/PingFang.ttc (stb_truetype)
  --system-emoji  → emoji face = macOS Apple Color Emoji.ttc (`sbix` PNG strikes)
Cell size is runtime (`cellw`,`cellh`, default 8×16), set by `--scale`/`--cell-h`.

## Phase 1 — stb_truetype text face + glyph cache + scale
- Vendor `tools/vendor/stb_truetype.h` + `stb_image_resize2.h`.
- Bundle DejaVu Sans Mono, subset (fonttools) to Latin-1/Ext-A, Greek, Cyrillic,
  punctuation, arrows, box drawing, block elements, geometric shapes, misc symbols →
  `tools/vendor/vt_font_ttf.h` (xxd), <100 KB. `make gen-font-ttf` regenerates (nix).
- Add a `Face` type + `render_glyph(cp,cellw,cellh)` rasterizing via stb_truetype
  with a glyph cache (cp→coverage+metrics). Replace `glyph()`/`vt_font.h`. Cell
  metrics from the font at `cellh` (advance→cellw, or cellh/2).
- `--scale F` / `--cell-h N` set cellh (default 16); output = cols*cellw × rows*cellh.
- TESTS: render `é ─ ↑ Ω © ►` → those cells non-blank (pixel probe); `--cell-h 24`
  → expected larger dimensions; colour + Kitty-image render unchanged (golden/visual).
- ACCEPTANCE: previously-blank text renders, antialiased, at a selectable size.

## Phase 2 — fallback chain + CJK face (REQUIRED) + colour emoji
- Wire the ordered face chain into `rasterize()`.
- CJK face: bundle GNU Unifont (OFL) covering CJK-relevant BMP ranges (CJK Unified
  Ideographs, Hangul, Kana, CJK Symbols/Punctuation, Fullwidth) → `tools/vendor/
  vt_font_cjk.h` (~1 MB packed bitmaps), scaled to the cell; width-2 codepoints span
  2 columns. `make gen-cjk`. `--system-fonts` → PingFang.ttc as the CJK face, else Unifont.
- Colour emoji face: curated Twemoji subset embedded as PNG BYTES in
  `tools/vendor/emoji_atlas.h` (`tools/gen_emoji.py`), decoded lazily via the existing
  stb_image + decode-cache path, composited across the 2-cell slot. `--system-emoji` →
  parse Apple Color Emoji.ttc `sbix` (cmap→glyphID via stb_truetype, largest-ppem strike
  PNG), else Twemoji + stderr note. v1: single-codepoint emoji only (ZWJ/skin-tone deferred).
- TESTS: `日本語 中文 한국어` legible + 2-col spacing, positioned right vs Latin; `👋`
  → colour (non-gray) pixels; `--system-emoji`/`--system-fonts` produce a differing
  native glyph on macOS AND fall back gracefully when pointed at a bogus font path.
- ACCEPTANCE: CJK + colour emoji render; bundled path reproducible; system path works on macOS.

## Phase 3 — output size / quality / formats
- `--width N` (post-resize each frame, stb_image_resize2, aspect preserved) +
  `--bit-depth N` (→ msf_gif) + `--frames-dir DIR` (write frame_%05d.png; print the
  suggested `ffmpeg -framerate FPS -i frame_%05d.png … out.mp4` / animated-WebP
  command). vt_gif stays ffmpeg-free.
- Makefile: `gif-chat-demo` sensible size default; optional `mp4-chat-demo`.
- TESTS: `--width 400` → 400-px-wide output; `--frames-dir` → N PNGs; malformed-input
  no-crash retained.
